# CodeAlpha Stock Portfolio Tracker

This is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Uses Indian stock names
- Stores stock prices using a Python dictionary
- Takes stock name and quantity from the user
- Calculates investment for each stock
- Calculates total investment
- Handles unavailable stock names

## Stocks Included

- RELIANCE
- TCS
- INFY
- HDFCBANK
- ITC

## Technologies Used

- Python
- Dictionary
- Loops
- Conditional statements
- User input
- Basic arithmetic
